# SABOTAGE 2

Projeto desenvolvido para a disciplina de Desenvolvimento de Games, inspirado no clássico Sabotage.

## Sobre o Projeto

Sabotage 2 é um jogo casual de ação em estilo arcade desenvolvido utilizando Processing. O projeto busca recriar a experiência clássica dos jogos retrô da década de 1980, trazendo melhorias de fluidez, responsividade e organização visual, mantendo a essência do jogo original.

O jogador controla uma torre de defesa equipada com uma arma antiaérea responsável por proteger a base contra helicópteros inimigos e soldados paraquedistas.

O objetivo principal é sobreviver o maior tempo possível, eliminando inimigos antes que consigam invadir a base.

---

# Funcionalidades Planejadas

* Movimentação lateral do jogador;
* Sistema de disparos;
* Helicópteros inimigos;
* Paraquedistas;
* Sistema de colisão;
* Sistema de pontuação;
* Aumento progressivo de dificuldade;
* Efeitos sonoros;
* Sistema de ranking com registro de nomes;
* Interface retrô inspirada em jogos arcade clássicos.
